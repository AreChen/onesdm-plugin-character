## English

Download Characters lets you create named download profiles through OnesDM MCP. Each profile has its own Skill and can remember an engine, engine options, device User-Agent, request language, destination, network route, thread count, and progress window preference. Select a profile for an individual download and override its settings for that task.

Requires OnesDM 0.9.0 or newer. Import the plugin ZIP in **Plugin market → Import plugin**, then enable AI access for Download Characters. Your profiles remain available after updating or reinstalling the plugin.

## 中文

下载角色可通过 OnesDM MCP 创建并复用。每个角色有独立的 Skill，可保存下载引擎、插件选项、设备 UA、请求语言、目录、线路、线程数和窗口偏好。发起下载时可选择角色，并为当前任务覆盖相应选项。

需要 OnesDM 0.9.0 或更新版本。在「插件市场 → 导入插件」中选择插件 ZIP，再启用下载角色的 AI 接入。更新或重装插件会保留已有角色。
