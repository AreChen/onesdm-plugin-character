# OnesDM Download Characters

Download Characters is a data-only plugin for OnesDM 0.9.0 and later. Save named defaults for an engine, format, device User-Agent, request language, destination, route and progress window. Select a character for an individual download through MCP.

## Install

Get the plugin ZIP from Releases, import it in **OnesDM → Plugin market**, and enable AI access for the plugin. Refresh the MCP tool list. To package this checkout, run `python3 tools/package.py dist`. [Download the plugin](https://github.com/AreChen/onesdm-plugin-character/releases/latest)

Each character has a `SKILL.md` in the desktop profile's `plugin-data/character/skills/` directory. The package contains the guide. Character settings are protected with the desktop profile's local data protection, including saved engine options. Upgrade or reinstall the package to keep using those roles. Delete a role through MCP only when you choose to remove it.

[Plugin Skill](SKILL.md)
